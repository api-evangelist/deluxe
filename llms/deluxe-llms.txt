## What the API does

- Card payments: sale, authorize, capture, void, refund, batch, tip adjust, Level 2 / Level 3 data
- ACH / EFT: debit, credit, account verification, batch, reject handling
- Card present: EMV cloud-to-device processing on Ingenico Tetra terminals
- Customer vault: stored customers, stored instruments, tokens, cryptograms, network tokens
- Recurring billing: subscriptions
- Payment links and hosted / embedded payment forms
- Invoicing: draft, edit, share, clone, download, configuration
- Reporting: daily card and ACH settlement, monthly fee statements, authorized / captured / settled
  transaction reports
- Webhooks: eight event types with subscribe, unsubscribe, resend, report and test-fire operations

## Access

- Base URL (production): https://api.deluxe.com/dpp/v1  (legacy alternate: /dpp/v1/gateway)
- Base URL (sandbox): https://sandbox.api.deluxe.com/dpp/v1
- Auth: OAuth 2.0 bearer token in the Authorization header, plus a required partnerToken GUID header
- Token lifetime: 60 minutes; refresh at 45 minutes
- Credentials: NOT self-serve. Email isvinquiries@deluxe.com to request a Client ID and Client Secret.
- Pricing: none published. Merchant agreement, sales-gated.

## Runtime semantics an agent must know

- Business failures return **HTTP 200** with a non-zero `responseCode` in the body. Do not read the
  HTTP status to decide whether a payment succeeded.
- 57 published gateway/issuer response codes; 30 share the identical masked message "REQUEST DECLINED!".
- **No idempotency mechanism exists.** No idempotency header on createPayment, createRefund or any
  batch operation. Never auto-retry a money-moving POST — call searchPayments with your own orderId
  instead.
- **No rate limits are published** and no RateLimit-* / Retry-After headers are documented.
- **No webhook signature or shared secret** is documented. Re-fetch state from the API rather than
  trusting a webhook body.
- Reporting dates are MM/DD/YYYY, not ISO 8601.
- Pagination is `page`/`pageSize` on reports but `pageNumber`/`pageSize` in the invoice-search body.
- Identifiers are bare GUIDs with no type prefix.
- No deprecation policy, no Sunset header, no public status page, and an empty Release Notes page.
